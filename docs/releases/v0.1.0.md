# v0.1.0 release notes

## Scope

- **Package** `@puranderdua/ui@0.1.0` (published 2026-10-17): `Text` (body, lead, caption, label), `Heading` (display, h1–h3, `as` independent of `variant`), `Button` (primary, secondary; sm, md; `asChild`), `foundations.css`.
- **Registry** live on Vercel: `ds-foundations`, `ds-types`, `ds-utils`, `ds-typography`, `ds-button` at `/r/v0.1.0/` (the three planned items plus the dependencies they needed, D-038).
- **Site** `apps/site`: package Text/Heading, registry Button, ESLint rule keeping Button off the package import.
- **Storybook** `apps/docs`: Text, Heading and Button stories with the a11y addon.

## Evidence

- Clean install of both channels outside the repo: [`docs/evidence/clean-install-2026-10-17.md`](../evidence/clean-install-2026-10-17.md) (PASS, axe 0 violations).
- Site QA: Playwright + axe suite in `apps/site/e2e/` (heading order, keyboard, focus, axe, 320px, 200% zoom), run in CI against `next start`; manual keyboard and zoom pass recorded in [PROGRESS.md](../PROGRESS.md) (S11).
- Tokens: `pnpm tokens:check` (aliases, duplicates, deterministic output, contrast; all pairs AA).
- Unit and a11y tests: 52 in `packages/ui`.
- Button provenance: [`docs/provenance/button.md`](../provenance/button.md).

- Penpot specimen board and the side-by-side comparison are not done (Purander, optional).
- No update-path checks yet (registry 0.1.1, package upgrade); see the parking lot in PROGRESS.md.
- Colour is a single achromatic brand scale; no dark mode. Both are Release 1.
- `clean-install.yml` has not been run on GitHub (Linux, Node 22).

# Release 1 review — props table (R2 appendix)

Every public component's own props in `@puranderdua/ui@0.8.0` (`packages/ui/src` at `3e4a19b`), read from the source. "Base" says which native or Radix props are spread onto the rendered element. All components accept `className` (merged last through `cn`) and spread the rest of their props, so `style`, `id`, ARIA and `data-*` reach the root element unless a row says otherwise. `data-slot` is set by the component and cannot be overridden, except on `SelectGroup` and `SelectValue` (R11). Findings are in the [register](2026-11-14-release-1-review.md).

## Typography and actions

| Component | Prop            | Type                                       | Default                                          | Notes                                                              |
| --------- | --------------- | ------------------------------------------ | ------------------------------------------------ | ------------------------------------------------------------------ |

|           | `variant`       | `"body" \| "lead" \| "caption" \| "label"` | `"body"`                                         | Visual role, independent of `as`.                                  |
| `Heading` | `as`            | `"h1"` … `"h6"`                            | from `variant` (display→h1, h1→h1, h2→h2, h3→h3) | Base: `<h1>` props; `ref` is `HTMLHeadingElement`.                 |
|           | `variant`       | `"display" \| "h1" \| "h2" \| "h3"`        | `"h1"`                                           |                                                                    |
| `Button`  | `variant`       | `"primary" \| "secondary"`                 | `"primary"`                                      | Base: `<button>` props. Also written to `data-variant`.            |
|           | `size`          | `"sm" \| "md"`                             | `"md"`                                           | Also written to `data-size`.                                       |
|           | `asChild`       | `boolean`                                  | `false`                                          | Radix `Slot`; merges props and handlers onto the child.            |
|           | `type`          | native                                     | `"button"` (left unset with `asChild`)           |                                                                    |
| `Link`    | `variant`       | `"inline" \| "standalone"`                 | `"inline"`                                       | Base: `<a>` props.                                                 |
|           | `asChild`       | `boolean`                                  | `false`                                          | For `next/link`.                                                   |

|           | `externalLabel` | `string`                                   | `"(opens in a new tab)"`                         | The only string prop outside Banner video.                         |

## Vocabulary check

| Prop name   | Where                                                       | Meaning                                                                    | Consistent?                                                                                                     |
| ----------- | ----------------------------------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `variant`   | Text, Heading, Button, Link, Card                           | Visual role from a closed set.                                             | Yes. Card's `raised`/`accent` is a tone in all but name; acceptable because a Card also adds border and shadow. |
| `size`      | Button, Input, SelectTrigger, Container                     | Control metrics `sm`/`md`; for Container a max width.                      | Yes.                                                                                                            |
| `tone`      | Section, Banner                                             | Surface plus re-pointed roles (`.ds-tone-*`).                              | Yes (each offers the tones it supports).                                                                        |
| `as`        | 11 components + CardTitle                                   | HTML element, independent of the visual props.                             | Yes; `sidebarAs` for the second element.                                                                        |
| `asChild`   | Button, Link (+ every Radix part)                           | Render the child element instead.                                          | Yes. Text, Heading and Card use `as` instead.                                                                   |
| `gap`       | Grid, Stack, Cluster, Split, Sidebar                        | `LayoutGap` step.                                                          | Yes (defaults `md` or `lg` by component).                                                                       |
| `align`     | Stack, Cluster, Split, Banner, SelectContent                | Cross-axis alignment, except Banner (main axis) and SelectContent (Radix). | **No** (R10).                                                                                                   |
| `justify`   | Cluster                                                     | Main-axis distribution.                                                    | Yes; Banner's `align` would be `justify` here.                                                                  |
| `container` | Section, Banner, SelectContent                              | A `ContainerSize` on Section/Banner; a portal element on SelectContent.    | **No** (R10).                                                                                                   |
| `side`      | Sidebar, SelectContent (Radix)                              | `start`/`end` edge vs popper side `top`/`right`/`bottom`/`left`.           | **No** (R10).                                                                                                   |
| `id`        | Field, Fieldset, every control                              | The control's id on Field; the element's own id everywhere else.           | **No** (R06).                                                                                                   |
| `required`  | Label, Field, Fieldset, controls                            | Required state; Field/Fieldset pass it to the control.                     | Yes.                                                                                                            |
| `*Label`    | Link `externalLabel`, Banner video `pauseLabel`/`playLabel` | Translatable string with an English default.                               | Yes.                                                                                                            |
| Controlled  | Checkbox, RadioGroup, Select, Tabs                          | Radix `value`/`defaultValue`/`on*Change` pairs.                            | Yes. BannerVideo's play state is uncontrolled only.                                                             |

# Screen-reader script — VoiceOver + Safari — 2026-11-14

Written in R5 of the Release 1 review (D-087) for the maintainer to run. Findings from it go into the [review register](../audits/2026-11-14-release-1-review.md) as new rows (kind `defect` or `recommendation`, area J).

**Setup:** macOS with the current Safari, VoiceOver on (Cmd+F5), verbosity default. Site: https://ui-design-system-beta.vercel.app (production, theme Base). Clear the site's data first (Safari > Settings > Privacy > Manage Website Data) so no stored theme or playground state is applied. VO = Control+Option.

**How to record:** for each step, write what VoiceOver said (roughly) and mark **pass** if it matches the expectation in meaning, **fail** if something is missing, wrong or announced twice. Note the Safari and macOS versions.
